⚡ EV-POS (Electric Vehicle Point of Sale System)
EV-POS is a high-performance e-commerce solution tailored for the electric vehicle industry. This platform leverages a Laravel backend and a reactive React frontend via Inertia.js, providing a smooth Single Page Application (SPA) experience.

https://kks-portfolio.vercel.app

✨ Key Features
Integrated Authentication: Secure Login and Registration system with personalized user profiles.

Dynamic Cart Management: Add, update quantities, or remove products with real-time feedback.

Streamlined Checkout: An optimized flow from cart management to the final payment interface.

Order Tracking: Detailed view of transaction records and real-time order status tracking.

Product Customization: Support for specific variants, including color options and technical specs.

Responsive Design: Crafted with Tailwind CSS for a consistent experience across all devices.

🛠️ Tech Stack
Backend: Laravel (PHP)

Frontend: React.js / Inertia.js

Styling: Tailwind CSS

Database: MySQL

⚙️ Local Installation Guide
Clone Repository:
git clone https://github.com/pk-1111/Ev-POS.git
cd Ev-POS

Install Dependencies:
Run "composer install" and "npm install" in your terminal.

Environment Setup:
Copy .env.example to .env and run "php artisan key:generate".

Database Migration:
Run "php artisan migrate --seed" to set up your tables.

Run Project:
Run "npm run dev" for frontend assets and "php artisan serve" for the backend server.
